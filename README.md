# Papelaria Ponto Certo
Projeto de Lógica de Programação - 4o bimestre

## Semana 21: Programando com menu no terminal
Nesta semana, você vai aprender a criar menus no terminal, organizar o código com funções, validar entradas e construir, passo a passo, um menu funcional, ampliando o projeto com a primeira opção executável.

### Aula 03: Construindo o menu do projeto
**Objetivo:** implementar o menu da Papelaria Ponto Certo utilizando repetição, estruturas de decisão e funções para controlar o fluxo do programa.

### Aula 04: Ampliando o sistema da Papelaria Ponto Certo
**Objetivo:** ampliar o programa desenvolvido nas aulas anteriores, tornando o cadastro de produtos mais confiável e implementando a consulta de produtos no mesmo menu.

## Semana 22: Agenda e cadastros em memória
Nesta semana, você vai aprender a armazenar dados em memória e desenvolver as principais operações de um cadastro: incluir, consultar e listar informações, aplicando esses conceitos ao projeto de uma agenda.

### Aula 03: Implementando o cadastro e a consulta de produtos
**Objetivo:** implementar e testar as funcionalidades de cadastro e consulta de produtos utilizando listas em memória no sistema da Papelaria Ponto Certo.

### Aula 04: Finalizando a primeira versão do sistema
**Objetivo:** ampliar o sistema da Papelaria Ponto Certo com a funcionalidade de listagem de produtos armazenados em memória, tornando o cadastro mais completo e fácil de utilizar.

## Semana 23: Médias, faixas e classificação
Nesta semana, você irá transformar critérios em regras de classificação, organizar cálculos de forma clara e reutilizável e aplicar médias para classificar dados, ampliando o projeto com a criação de rankings.

### Aula 03: Desempenho de vendas no sistema da Papelaria Ponto Certo
**Objetivo:** criar uma nova funcionalidade no sistema capaz de: informar um produto → calcular sua média de vendas → classificar o desempenho → exibir o resultado.

### Aula 04: Ampliando o sistema: ranking de desempenho
**Objetivo:** Criar uma funcionalidade que: processe vários produtos → organize os resultados → monte um ranking → salve e exiba o resultado.
